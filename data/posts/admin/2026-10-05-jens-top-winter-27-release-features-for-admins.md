- The post is an admin-focused guide to Winter '27 highlights, with the reminder that the 600+ page release notes don't need to be read in full, and it explains pilot, beta and GA feature phases.
- Two new User Interface Settings (off by default) allow list view inline editing of any field the user can access, even if it isn't on the page layout, and across lists with multiple record types.
- User Field History Tracking is now GA and auto-enabled, tracking up to 20 User fields with data retained for up to 18 months in the UI.
- A new 'Keep manual shares when transferring records' sharing setting stops Salesforce from deleting manual shares on owner change, and Custom Row Causes for standard objects via Metadata API are targeted for October 10, with Setup management by early November (forward-looking).
- Email and MFA updates include a User Email Domains page, importing authorized email domains into sandboxes from production, per-domain verification rules (Always, For Updated Addresses Only, Never), and Chrome extension entries (`chromeextension://[32-char-id]`, no wildcards) in Trusted URLs.
