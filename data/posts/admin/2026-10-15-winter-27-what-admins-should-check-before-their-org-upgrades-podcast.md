- Builder Central (beta) is an agent-powered workspace where admins describe an app or agent in natural language, and it plans, builds in a virtual environment, lets you preview and tweak the result, and then deploys from sandbox to production.
- Setup with Agentforce is now GA. It no longer requires Data 360, though related list enrichments and custom report types still need it, and its two permission sets are now bundled into a single permission set group.
- Setup with Agentforce can bulk freeze/unfreeze users, trigger password resets, summarize permission sets and groups, find profiles with specific permissions, and reorganize role hierarchies.
- Flow gets three Winter '27 enhancements: Edit History (review, restore and reuse past versions), multi-record processing with Screen Flows from List Views and Related Lists, and Test Mode (beta) with saved manual tests that can seed an automated test suite.
- A new sharing setting, 'keep manual shares when transferring records', preserves manual shares when record ownership changes, which previously dropped them silently.
